Cybersecurity

"SSHole" OpenSSH flaw under active exploitation

Attackers are exploiting CVE-2026-123158, an OpenSSH authentication-bypass bug (CVSS 8.1) affecting servers built on musl libc with PAM disabled — notably Alpine Linux's default configuration — to run commands, steal credentials, and plant persistent access. GreyNoise clocked the first in-the-wild exploitation within roughly 40 hours of the patch shipping; a fix is available in OpenSSH 10.6p2.

BleepingComputer

Ivanti Connect Secure zero-day chain: second CISA deadline hits tomorrow

CISA added two more Ivanti Connect Secure flaws — CVE-2026-111357 (missing authentication) and CVE-2026-118527 (predictable identifiers) — to its Known Exploited Vulnerabilities catalog after they were chained together in zero-day attacks. Federal agencies had until November 2 to remediate the first; the deadline for the second lands November 13.

Help Net Security

APT package manager flaw lets network attackers run code as root

Debian, Ubuntu, and the APT project disclosed a flaw where an attacker positioned between a host and its package mirror can slip in an unverified package when APT retries a failed download — the default behavior since Debian 12 and Ubuntu 22.04. The injected code then executes with root privileges, making it a serious supply-chain risk for Linux fleets.

The Hacker News

Zyxel GS1900 switches hit by zero-day that survived an earlier patch

Researchers say an attacker exploited roughly 1,000 Zyxel GS1900 switches across 48 countries using CVE-2026-107441, a separate, unpatched flaw that kept working even on devices already updated against a related June bug. Zyxel shipped Patch 3 firmware on October 22 and published its advisory November 3; admins should apply the new patch even if the earlier one was already installed.

CISA adds four more flaws to its Known Exploited Vulnerabilities catalog

This week's additions span AI infrastructure and enterprise software: GPUStack (improper authentication), SignalWire FreeSWITCH (code injection), OpenBSD OpenSSH, and IBM Aspera Faspex (incorrect authorization). All four are confirmed as actively exploited, and federal agencies face standard BOD 22-01 remediation deadlines.

OpenAI cuts off Cursor's model access today, after SpaceX's buyout

OpenAI is winding down the contract that supplies its models to Cursor, with a shutoff date of November 12 — today — following SpaceX's roughly $60 billion all-stock acquisition of Cursor's parent company, Anysphere.
