ChainDrop worm poisons 1,300+ npm packages with 2 billion monthly downloads

A self-propagating supply-chain worm dubbed ChainDrop compromised the GitHub account of a popular maintainer and spread through packages like Keyv, Cacheable, flat-cache and file-entry-cache, reaching projects tied to Deliveroo, Qlik and ServiceTitan. Because the poisoned releases were built through legitimate CI pipelines, they carried valid provenance data while a hidden installer script hunted for npm, GitHub, cloud and database credentials.

Maximum-severity Cisco ISE bug (CVSS 10.0) under active exploitation

CVE-2026-76460 lets an unauthenticated attacker send a single crafted request to bypass Cisco Identity Services Engine's management interface and reach command execution with root privileges. Cisco has confirmed in-the-wild exploitation and CISA has added the flaw to its Known Exploited Vulnerabilities catalog; there is no workaround, only an upgrade.

Attackers are actively exploiting CVE-2026-46817, a critical, unauthenticated takeover flaw in the File Transmission component of Oracle EBS's Payments module. Oracle patched the bug in its May Critical Patch Update, but researchers say exploitation attempts are continuing against the hundreds of exposed instances still found scanning the public internet.

"KindaRails2Shell" Ruby on Rails flaw now being exploited for RCE

CVE-2026-66066 abuses unsafe libvips image-processing operations in Rails' Active Storage component, letting an unauthenticated attacker read arbitrary files — including secret keys and credentials — via a crafted upload, which can escalate to full remote code execution. VulnCheck says exploitation began roughly a month after patches shipped, with thousands of vulnerable instances still exposed.

Russian "CaptiveCrunch" campaign hijacks hotel Wi-Fi to phish business travelers

Microsoft attributes a global campaign to Storm-2945, a sub-cluster of Midnight Blizzard (APT29), which manipulates hotel and conference-venue captive portals to redirect travelers to fake Microsoft 365 logins, device-code phishing pages, and bogus OS/browser update prompts. The resulting malware can log keystrokes and activate cameras and microphones, with government, diplomatic and NGO staff among the primary targets.
