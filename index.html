Reactivated GitHub Actions resume running Shai-Hulud malware, months after first compromise

Two actions-cool GitHub Actions became publicly accessible again on September 16 without their poisoned release tags being cleaned up, so any workflow still referencing them by version resumed pulling malicious code first planted during May's Mini Shai-Hulud supply-chain campaign. The payload harvests CI/CD credentials and exfiltrates them to attacker infrastructure, and researchers disabled the actions for a second time this week.

The Hacker News

"SalesBleed" flaws let attackers hijack Salesforce Agentforce agents with zero clicks

Zenity Labs disclosed three Agentforce vulnerabilities that can be triggered through poisoned Web-to-Lead form submissions: hidden instructions sit dormant in a CRM lead until an employee asks an agent to process it, then execute automatically. Two of the three enable zero-click data exfiltration to attacker servers, and a third lets attackers impersonate a trusted Agentforce-connected Slack bot to phish staff; Salesforce says all three have been patched.

SecurityWeek

Astrana Health discloses breach after attackers vished their way onto its servers

The healthcare services company told the SEC that attackers impersonated Astrana personnel and spoofed the firm's own corporate phone number to trick employees into granting internal system access. Astrana says it has restored systems from clean backups and is still assessing whether patient, employee, provider, or financial data was accessed or exfiltrated.

SecurityWeek

Gyazo breach exposes 23.6 million user records after image-server flaw exploited

Japanese operator Helpfeel confirmed attackers exploited a vulnerability in the screenshot-sharing service's upload server to run arbitrary commands and steal roughly 23.6 million user records, including names, emails, password hashes, and billing details, plus metadata for 490 million images. The company cut off access within hours of detecting the intrusion and is urging all users to reset their passwords.

BleepingComputer

Chained SonicWall SMA1000 flaws under active exploitation, enable unauthenticated RCE

CVE-2026-83548, a maximum-severity pre-auth SSRF in the SMA1000 Work Place interface, can be chained with CVE-2026-83549, an OS command injection bug in the appliance's admin console, to give an unauthenticated attacker remote code execution. SonicWall and CISA have confirmed real-world exploitation; both flaws are now in the KEV catalog and the appliances sit on the network edge, often exposed directly to the internet.
