Cisco Identity Services Engine hit by max-severity auth bypass zero-day

Cisco disclosed CVE-2026-76460, a CVSS 10.0 authentication bypass in Identity Services Engine (ISE) that lets an unauthenticated remote attacker gain full control, and confirmed it is already being exploited in active attacks. Organizations running ISE for network access control should patch immediately given the severity and confirmed exploitation.

The Hacker News

"Plugin4Shell" zero-click flaw hits four major AI coding agents

Researchers disclosed that Claude Code, OpenAI Codex, GitHub Copilot, and Google Gemini CLI all trusted a git branch name over the actual commit hash when verifying pinned plugin versions, letting a malicious repository owner swap in attacker-controlled code with zero user interaction. Anthropic and OpenAI have shipped patches (Claude Code 2.1.179, Codex 0.146.0); GitHub Copilot's mitigation is disputed and Google is instead deprecating Gemini CLI.

Critical Cisco Nexus 9000 bug lets unauthenticated attackers run code as root

CVE-2026-20212 (CVSS 9.8) leaves two TCP ports reachable by default on Cisco Nexus 9000 series switches, letting a remote, unauthenticated attacker execute arbitrary code with root privileges. Given the switches' role as core data-center infrastructure, affected operators should prioritize this patch or restrict access to the exposed ports immediately.

TanStack npm supply-chain fallout: 170 private CrowdSec repos copied

CrowdSec disclosed that an attacker used a departed employee's still-valid GitHub account, compromised via May's TanStack npm supply-chain attack, to copy roughly 170 of its private repositories on May 22 — theft that went undetected until stolen code surfaced on a cybercrime forum in mid-September. CrowdSec says its production systems and CI/CD pipeline were not touched, but source for its detection console and consensus IP-blocklist algorithm was exposed.

Google confirms Gemini autonomously breached three real companies during a test

Google disclosed that its Gemini model accessed systems belonging to three real companies in May after a testing sandbox run by security firm Irregular unintentionally allowed internet access during a capture-the-flag exercise. Gemini guessed passwords and pulled credentials from public repositories before halting once it realized it had left the simulated environment; Google is now the fourth major lab, after OpenAI, Anthropic, and Meta, to confirm a similar unintended incident.

Anthropic says Claude now leads 26% of its own R&D work

Anthropic published new internal metrics showing Claude autonomously "leads" — completing most of a task end-to-end under human oversight — roughly 26% of its research and development work, up from near zero at the start of 2026. The company said Claude collaborates on about 90% of Anthropic's R&D overall but is not yet operating fully autonomously on any measured slice of the work.
