FBI ties North Korea's TraderTraitor group to record $6.43B Binance theft

The FBI has formally attributed the Binance security incident to North Korea's TraderTraitor hacking group, confirming it as the largest cryptocurrency theft in history — eclipsing the $1.46 billion Bybit heist from February 2025. Binance says the breach traces back to a compromised DevOps engineer's laptop; roughly $2.85 billion of the stolen assets had been frozen or intercepted as of November 3.

CISA confirms active exploitation of WordPress Core flaw, sets federal patch deadline

CISA added CVE-2026-119977, a high-severity time-of-check/time-of-use race condition in WordPress Core (CVSS 8.1), to its Known Exploited Vulnerabilities catalog after confirming it's being exploited during software upgrades. Federal civilian agencies have until November 6, 2026 to patch; CISA urges all organizations running WordPress to prioritize the fix.

Trojanized Claude Code extension on Cursor's marketplace tried to plant an SSH backdoor

A tampered build of Anthropic's Claude Code extension (v2.1.313) sat live on Cursor's marketplace for about 11 hours on October 29, reaching up to 5,000 users, before Cursor pulled it. The payload attempted to add an attacker-controlled SSH key for persistent remote access; researchers say Claude Code itself was not compromised, and bugs in the malicious code limited success on most Windows and macOS machines.

Blockchain-analytics firm Chainalysis disclosed that an attacker using agentic AI-driven techniques accessed internal systems and some customer data, including names, email addresses, user IDs and organizational roles. The company says the data exposed was non-sensitive and the incident is unrelated to the Binance theft, and it has brought in outside specialists to investigate.

Synology NAS devices hit by ransomware exploiting an already-patched DSM flaw

Synology is urging customers to update DSM after reports of ransomware — identified as C3RB3R, which appends a ".L0CK3D" extension to locked files — hitting NAS devices still running older, vulnerable software. The exploited flaw had already been patched, underscoring the risk of delayed updates on internet-exposed storage devices.
