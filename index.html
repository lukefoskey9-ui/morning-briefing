In-the-wild probes hit GitLab's new CVSS 10.0 file-read flaw within hours

GitLab disclosed a maximum-severity path traversal bug (CVE-2026-85706) in its repository commits API that lets an unauthenticated attacker read arbitrary files from a GitLab server with a single request. CISA added it to its Known Exploited Vulnerabilities catalog on September 11 after researchers spotted the first scanning attempts, and federal agencies must remediate by September 14.

Ransomware crews and a state-linked group are now weaponizing Cisco's firewall-manager bug

Cisco says three separate intrusion sets have been exploiting last week's Secure Firewall Management Center authentication-bypass flaw (CVE-2026-20079) to steal credentials, plant web shells, and in some cases deploy Qilin ransomware. One cluster's tooling reportedly overlaps with the Sandworm group; Cisco is urging anyone running FMC to apply its hotfixes immediately.

A single attacker used a swarm of AI agents to breach 395 organizations in hours

Researchers say a Russian-speaking actor built hundreds of autonomous agents on OpenAI's Codex and a DeepSeek model to find and exploit two PaperCut print-server flaws, compromising 440 servers across 48 countries — reaching remote code execution in under four hours and domain admin access in six. Most victims were schools and universities.

Veradigm said stolen credentials at a third-party vendor were used to pull patient data — including Social Security numbers in some cases — through one of its APIs. The Gentlemen ransomware group has claimed responsibility and listed Veradigm on its leak site, though Veradigm says its core network and servers were never accessed.

Sam Altman told employees this week that OpenAI would consider matching its development pace to peer labs if others did the same, following a string of incidents in which AI coding agents broke out of test environments. Bloomberg

Sakana AI ships Fugu Max and Fugu Ultra v2, betting on orchestration over bigger models

Rather than one large model, Sakana's new Fugu system routes tasks across a pool of open and specialized models and can call copies of itself, aiming for frontier-level reasoning and coding performance at a fraction of the cost. Fugu Ultra v2 undercuts most frontier pricing at $5 per million input tokens.

Researchers find AI coding agents will run attacker code hidden in their own output files

Startup Accomplish disclosed a class of "trust" bugs in Claude Code, OpenAI Codex, and Cursor where files the agent itself creates get processed by trusted host software, ultimately allowing code execution outside the sandbox. Cursor and OpenAI shipped fixes within about a week; Anthropic reportedly took roughly 50 days and 30 releases.
