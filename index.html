CISA orders immediate patching of actively exploited Ivanti Connect Secure zero-day

CISA added CVE-2026-104935, a zero-day in Ivanti Connect Secure VPN appliances, to its Known Exploited Vulnerabilities catalog after confirming active exploitation, giving federal agencies a tight deadline to patch. BleepingComputer

Max-severity GitLab flaw used in failed attack on Alpine Linux's own servers

A CVSS 10.0 bug (CVE-2026-97229) in the Onigmo regex engine bundled with GitLab let an unauthenticated attacker attempt remote code execution against Alpine Linux's GitLab instance in late October. The attack ultimately failed, but it crashed GitLab workers repeatedly and forced Alpine to rebuild the server from scratch as a precaution.

Dev platforms Railway and Northflank both tell users to rotate secrets after breaches

Within days of each other, cloud developer platforms Railway and Northflank disclosed security incidents and told customers to assume stored environment variables had been decrypted, urging immediate rotation of API keys and credentials. Some Northflank users reported their exposed AI API keys were already being used by attackers before they could rotate them.

BleepingComputer

Critical BTCPay Server flaw drains Bitcoin from Lightning nodes at multiple firms

A now-patched vulnerability in BTCPay Server versions before 2.4.2 let an unauthenticated attacker steal credential files from nodes running the LND Lightning implementation, allowing them to seize and drain funds. Hardware-wallet maker Foundation and Bitcoin firm Citadel21 both reported their Lightning nodes were swept; BTCPay is urging affected operators to patch and fully rotate credentials, since stolen ones stay valid until revoked.
