Cybersecurity

LiteLLM's PyPI package backdoored in a second supply-chain attack

A malicious version of the popular LiteLLM AI-proxy package (v1.107.0) was uploaded to PyPI on Oct 21 and quarantined about 13 hours later. Wiz says it carried a credential stealer targeting cloud, browser, and AI secrets, and that the attacker used GitHub CLI OAuth tokens stolen from three maintainers' accounts — the project's second PyPI compromise this year.

"PHP2Shell" flaws force emergency patches across nearly every PHP site

The PHP team rushed out fixes on Oct 21 for two linked, unauthenticated remote-code-execution flaws (CVE-2026-109618, CVE-2026-109619) affecting PHP-FPM, mod_php, php-cgi, FrankenPHP, and LiteSpeed — effectively any PHP install that serves web requests. Wiz demonstrated working exploits against stock WordPress, Drupal, and Joomla deployments; patched releases are 8.5.12, 8.4.27, 8.3.36, and 8.2.35.
