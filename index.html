Cisco ISE zero-day patched at a perfect CVSS 10 — already under active attack

CVE-2026-76460 is an authentication-bypass flaw in Cisco Identity Services Engine and ISE-PIC caused by insufficient checks on an API endpoint, letting an unauthenticated attacker send a crafted request and gain root-level command execution. Cisco PSIRT confirmed active exploitation and CISA added it to its Known Exploited Vulnerabilities catalog with a federal patch deadline of September 19; there is no workaround, only the fixed release.

Second Cisco flaw this week: unauthenticated root code execution on Nexus 9000 switches

CVE-2026-20212 (CVSS 9.8) comes from a service bound to an unrestricted IP address on Silicon One-based Nexus 9000 switches, leaving two TCP ports reachable to anyone who can reach the device; crafted input sent to that service executes as root and can also crash and reload the switch. Cisco says it isn't aware of public exploitation yet, but patches are available now.
