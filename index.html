Apple patches CoreGraphics zero-day used in "extremely sophisticated" targeted iPhone attacks

CVE-2026-20700, an out-of-bounds write in Apple's CoreGraphics rendering framework, may have been exploited against specific targeted individuals on iOS versions before iOS 27; simply processing a malicious file could trigger code execution. Apple shipped iOS/iPadOS 26.7.1 and macOS 26.7.1/15.8.1 fixes and recommends updating immediately, especially for anyone who might be a high-value target.

Cisco Secure Email Gateway zero-day lets attackers gain root with a single crafted email

CVE-2026-76461 (CVSS 9.8) is a SQL-injection flaw in the appliance's email-parsing logic that lets an unauthenticated attacker run arbitrary commands as root simply by sending a malicious message — no login or admin access required. Cisco has released fixed AsyncOS builds (15.5.5-014, 16.0.4-302, 16.5.0-780) and says there are no workarounds short of updating.
