Git patches critical RCE triggerable by cloning a malicious repository

CVE-2026-111760 lets an attacker exploit integer truncation in Git's index handling to swap a submodule's .git file for a symlink pointing at malicious hooks, which then execute automatically on a recursive clone. Git 2.56.1 and backports through 2.50.2 fix it, alongside five other bugs; until updated, advisories recommend avoiding recursive clones of untrusted repos.
