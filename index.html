Apple patches CoreGraphics zero-day as public exploit code surfaces

Apple's fix for CVE-2026-86950 — an out-of-bounds write in CoreGraphics that can lead to arbitrary code execution when a device opens a malicious file — closes a flaw Apple says was used in an "extremely sophisticated" attack against specific targeted individuals on iOS versions before iOS 27. A working proof-of-concept exploit is now circulating publicly, raising the risk of broader exploitation for anyone still on unpatched versions.

Node.js patches critical Brotli decoder flaw with public exploit code

Node.js shipped emergency fixes (22.23.4, 24.22.1, 26.12.1) on October 21 for CVE-2026-111497, a high-severity out-of-bounds write in the bundled Brotli decompression code reachable through node:zlib or fetch() responses using Brotli content-encoding. Proof-of-concept code that can crash affected services is already public; researchers say full remote-code-execution exploitation hasn't been demonstrated yet, but patching now is strongly advised.

Cybernews

FBI and CISA: SafePay ransomware has hit 600+ organizations since 2024

A joint advisory details how the SafePay ransomware group has struck businesses and critical infrastructure across North America, South America, Europe and Australia, gaining initial access through stolen VPN credentials, brute-forcing, and known flaws in Cisco ASA/FTD, Veeam Backup & Replication, and SonicWall SonicOS. The group also deletes shadow copies and wipes NAS-based backups to block recovery. CISA urges prioritizing patches for internet-facing VPNs and firewalls plus MFA and offline, immutable backups.

eSecurity Planet

HashiCorp Consul authorization bypass let RBAC rules match too broadly

CVE-2026-88021 stems from Consul generating Envoy RBAC rules without properly escaping special characters in service names, namespaces and partitions — letting generated rules match more traffic than intended inside the Connect service mesh. A related flaw, CVE-2026-87090, let an authenticated attacker delete another node's catalog registration and seize its identity. Both are fixed in Consul 2.0.4 and the corresponding Enterprise releases; the Canadian Centre for Cyber Security has also issued an advisory.

Zimbra RCE flaw keeps claiming unpatched servers

Microsoft found attackers exploiting CVE-2026-73570 — an OS command-injection bug in Zimbra Collaboration Suite's optional SNMP component — within days of the July 20 patch, before public disclosure. CISA added it to its Known Exploited Vulnerabilities catalog on August 21, but scans have continued turning up hundreds of compromised instances and thousands more still unpatched, underscoring how slowly some organizations apply fixes even for actively exploited bugs.

Google starts rolling out Gemini 4 Argon — but only to vetted cyber defenders

Argon is Google's first Gemini 4-generation model to ship, but initial access is deliberately restricted to trusted partners through its "Fairwind" cyber-defense program before any wider release.
