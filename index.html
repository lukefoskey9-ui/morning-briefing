"Plugin4Shell" zero-click flaw hits four major AI coding agents

Researchers found that Claude Code, OpenAI Codex, GitHub Copilot, and Google Gemini CLI failed to verify that a git checkout actually landed on the pinned commit hash they expected, letting a malicious repo owner swap in attacker-controlled code during automatic plugin updates with no user interaction required.
