Debian & Ubuntu patch APT flaw that lets attackers plant malicious packages as root

A newly disclosed bug (CVE-2026-109518) in the APT package manager lets a network attacker who can tamper with HTTP traffic swap a verified package for a malicious one, which then runs as root. It affects Debian 12+/Ubuntu 22.04+ by default because of their retry settings; using HTTPS repositories blocks the attack. Fixes are out for Debian and Ubuntu.
