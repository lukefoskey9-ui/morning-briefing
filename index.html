The 24–48 hours that mattered

Cisco patches second actively exploited zero-day in as many days, this one a perfect 10

CVE-2026-76460 is an authentication bypass in Cisco's Identity Services Engine (ISE) and ISE-PIC, caused by insufficient authentication on an API endpoint, letting an unauthenticated attacker gain full control of the device. Because ISE enforces network access policy, a compromised box lets attackers rewrite policy, pull stored credentials, and pivot into every segment it controls; CISA gave federal agencies three days to patch.

The Hacker News

"MikroTrick" SSH exploit chain leaves 120,000+ MikroTik routers exposed

CERT Polska detailed a two-bug chain — an RSA key-verification bypass (CVE-2026-67276) and a privilege-escalation flaw (CVE-2026-86060) — that lets an attacker take full unauthenticated control of MikroTik RouterOS devices over SSH. Exploitation began around September 2, a day before patches shipped, and a single scan found more than 120,000 internet-facing devices still vulnerable.

CERT Polska

Chinese-speaking actor quietly compromised nearly 1,000 Zyxel switches since August

Attackers have been exploiting a stack-based buffer overflow (CVE-2026-7273) in unpatched Zyxel GS1900 switches since August 17, using an obfuscated Python tool to pull device configs, network topology data, and hashed root credentials from 996 switches across 48 countries. Zyxel patched the flaw back in June; CISA has now ordered federal agencies to remediate by September 24.

Extortion gang ShinyHunters hacks and defaces rival Clop's ransomware leak site

ShinyHunters says it exploited a file-upload flaw in the Grav CMS running Clop's dark-web leak site, defaced it, and stole source code, logs, and the private keys behind Clop's onion service. The group is now demanding an eight-figure payment from Clop itself in an escalating feud between the two cybercrime operations, with claims of stolen data not yet independently verified.

The Register

Zero-click "Plugin4Shell" flaw hits Claude Code, Codex, Copilot, and Gemini CLI

Researchers disclosed a supply-chain flaw that lets a malicious plugin update slip past SHA-pinning checks and run code with no user interaction, since these coding agents auto-update plugins in the background by default. Anthropic and OpenAI have shipped fixes (Claude Code 2.1.179, Codex 0.146.0); Microsoft's Copilot remains unpatched and Google retired Gemini CLI without fixing it.

Help Net Security

GitLab's maximum-severity file-read flaw still drawing active probes

CVE-2026-85706, a CVSS 10.0 path traversal in GitLab's commits API, lets an unauthenticated attacker read arbitrary files — including secrets and config — off self-managed GitLab servers. Mass internet scanning began within hours of the patch, and CISA added it to its Known Exploited Vulnerabilities catalog; unpatched self-managed instances remain at serious risk.

Security vendor Aikido ships Altar-1, an open-weight model built to run on-prem

Aikido released Altar-1, a pruned, open-weight model derived from GLM-5.3, designed to run vulnerability-hunting and pentesting workloads entirely inside a customer's own infrastructure rather than a cloud API. It's aimed at banks, healthcare providers, and other organizations that can't send source code or security findings to external inference services, and it's already finding critical bugs in Aikido's own production systems.
