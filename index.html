CISA flags Cisco BroadWorks flaw as actively exploited

CISA added CVE-2026-20320 — an unauthenticated XXE flaw (CVSS 7.5) in the BroadWorks OCI XML parser — to its Known Exploited Vulnerabilities catalog on November 10, giving federal agencies until November 24 to patch. The bug, which Cisco disclosed in August, can let a remote attacker read sensitive files; Cisco's fix is release RI.2026.07 and there is no workaround.

"Node2Shell" Brotli flaw under active exploitation

CISA confirmed in-the-wild exploitation of CVE-2026-111497, an out-of-bounds write in the Brotli decompression library bundled with Node.js, Microsoft's .NET, and VMware products — security firms logged exploitation attempts in late October. Rated critical (CVSS 9.2), the flaw allows memory exposure and potential remote code execution; there's no workaround, so updating Node.js (22.23.4, 24.22.1 or 26.12.1) or the relevant .NET/VMware patch is the only fix.

Chained AhsayCBS bugs used to plant a sandbox-evading Python backdoor

Researchers at Huntress and Bitdefender detail a campaign chaining two AhsayCBS backup-platform flaws — an auth bypass (CVE-2026-105133) and a command-injection bug (CVE-2026-105134) — to deploy webshells, a cryptominer, and a Python implant that refuses to run outside its intended host to frustrate analysis. Both CVEs are now in CISA's KEV catalog; Ahsay's fix is v10.3.4.45 (v10) or v9.15.2.70 (v7–v9), and affected organizations should also hunt for leftover webshells.

Google dismantles 1.3-million-device Android TV botnet, bans the manufacturer

Google and partners took down XCPE, a botnet built from malware baked directly into device firmware by Shenzhen-based manufacturer Videostrong — not a vulnerability or user error. Google revoked Videostrong's certified Android TV license, banned its future subsidiaries, and moved legally against the botnet's control infrastructure, though the dormant backdoor code remains on affected devices, including some TV boxes, telehealth units, and karaoke machines.

Nvidia's GR00T 2 teaches robots skills mostly by watching humans

Unveiled November 9 at the Conference on Robot Learning, Nvidia's GR00T 2 trained on roughly 400,000 hours of first-person human video plus smaller sets of gripper and teleoperation data. In simulation, success on 50 tasks never demonstrated on the test robot rose from 40% to 95% after just five examples; Nvidia is releasing a 100,000-hour slice of the human-video dataset openly, and says Foxconn and Siemens are already testing the model.

Google DeepMind uses AI agents to formally verify Signal's encryption code

DeepMind's AlphaProof Code framework had AI agents write machine-checked mathematical proofs — verified by the Lean proof assistant — of key security properties in the Signal protocol's actual implementation, which DeepMind calls the first formal verification of a widely deployed protocol's code by any method. The four-week proof-of-concept found no new vulnerabilities but didn't cover the entire Signal app, and DeepMind is releasing the verification artifacts for others to build on.
